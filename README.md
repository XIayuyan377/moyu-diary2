# 摸鱼日记 - 赛博宠物桌面伴侣

> 给研究生打工人的温柔讽刺 + 自嘲治愈 + 一只熊猫陪伴

## 🐼 项目概述

**摸鱼日记**是一个面向研究生和长期工位打工人的桌面应用，通过一只可爱的熊猫赛博宠物陪伴用户记录工作状态、追踪情绪变化，在温柔的讽刺和自嘲中获得治愈。

### 核心特性
- 🐼 **赛博宠物陪伴** - 一只有情绪的熊猫，会根据你的工作状态变化
- 📝 **工作日记记录** - 温柔讽刺的工作备忘，用自嘲来记录
- 📊 **情绪和活力追踪** - 可视化你的工作状态变化
- 💭 **温柔碎碎念** - 熊猫会说出"有品质的摸鱼"建议
- 🎯 **周工作量统计** - 用数据说话，看看这周你摸了多久

## 🎨 视觉设计规范

### 设计理念
**奶油手账插画风** - 像一本有温度的手账本，充满圆润、暖色、有细节的设计元素

#### 禁忌
❌ 极简冷酷  
❌ 赛博朋克  
❌ 暗黑风  

#### 要求
✅ 圆润、暖色  
✅ 有细节、像在撒娇  
✅ 温度感、人情味  

### 配色方案

```css
/* 背景色系 */
```

## 💡 设计细节说明

### 熊猫宠物设计
- 默认表情：慵懒摸鱼状
- 工作中：认真脸 🐼
- 高兴状态：咧嘴笑 😊
- 疲惫状态：眯眼 😴
- 会根据情绪值和活力值自动切换表情

### 温柔讽刺文案
熊猫会说：
- "又开始摸鱼了呢~"
- "该喝水了，别忘了💧"
- "坚持住，下班还远呢"
- "今天的提交了吗？"
- "你的热情值得被看见❤️"
- "摸鱼也要摸得有品质"

### 色彩使用规则
- **竹叶绿** (#5BAD7F) - 主要CTA、确认操作
- **暖橘** (#FF8C42) - 重要提示、活跃状态、特殊关注
- **米白** (#FAF7F2) - 背景，给人温暖放松的感觉
- **暖棕** (#3D3530) - 文字，配合米白保证可读性

## 📝 使用场景

### 典型用户流程
1. 早上9点打开应用，看熊猫说早上好
2. 记录今天要做的工作
3. 全天记录工作进度和摸鱼时间
4. 熊猫根据工作量调整情绪值
5. 晚上可以看到今日统计和周报告
6. 下班前，熊猫会说"辛苦了，明天见"
